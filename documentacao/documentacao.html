Objetivo: desenvolver um sistema web fullstack em camadas para cadastro de produtos, registro de vendas e consulta de compras, com persistência em banco de dados.

1. Tecnologias e arquitetura

  • Front-end: HTML5, CSS3 e JavaScript.
  • Back-end/API: Node.js e Express.
  • Persistência: SQLite com Better SQLite3.
  • Arquitetura: interface web → API REST → camada de banco de dados.

2. Funcionalidades

  • Listagem, pesquisa e filtro de produtos.
  • Carrinho com alteração de quantidade e total.
  • Registro de cliente e venda, com baixa automática no estoque.
  • Consulta do histórico de compras pelo e-mail.
  • Painel administrativo para cadastrar, editar e desativar produtos.
  • Consulta de vendas e atualização do status do pedido.

3. Como executar

  1. Instale Node.js 18 ou superior.
  2. No terminal, acesse backend.
  3. Execute npm install.
  4. Execute npm run seed.
  5. Execute npm start.
  6. Acesse http://localhost:3000.

Senha administrativa inicial: admin123.

5. API REST

  • GET /api/products: lista produtos.
  • POST /api/products: cadastra produto.
  • PUT /api/products/:id: altera produto.
  • DELETE /api/products/:id: desativa produto.
  • POST /api/sales: registra venda.
  • GET /api/sales?email=...: consulta compras.
  • PATCH /api/sales/:id/status: altera status.

6. Banco de dados

As tabelas são categories, products, customers, sales e sale_items. As chaves estrangeiras preservam o relacionamento entre clientes, vendas, itens e produtos. A operação de venda utiliza transação para evitar registros incompletos.

7. Considerações finais

O projeto atende às funcionalidades mínimas da opção E-commerce e adiciona carrinho, estoque, categorias, status e painel administrativo. O código foi separado nas pastas solicitadas.
